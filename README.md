# AIML Tech Stack & Project Portfolio

Welcome to my comprehensive Artificial Intelligence and Machine Learning (AIML) repository. This project serves as a centralized hub showcasing my expertise across the entire spectrum of modern AI—ranging from classical machine learning algorithms to cutting-edge Generative AI, Multi-Agent Orchestration, and production-ready API deployment.

---

## 🚀 Tech Stack Overview

### 1. Core AIML & Deep Learning
* **Data Manipulation & Analysis:** `NumPy`, `Pandas`, `SciPy`
* **Data Visualization:** `Matplotlib`, `Seaborn`
* **Classical Machine Learning:** `Scikit-Learn` (Regression, Classification, Clustering, Feature Engineering)
* **Deep Learning Frameworks:** `TensorFlow`, `Keras`, `PyTorch`

### 2. Generative AI (GenAI)
* **Large Language Models (LLMs):** OpenAI (GPT-4o), Anthropic (Claude), Google (Gemini), and Open-Source models via Hugging Face/Ollama (Llama 3, Mistral).
* **Frameworks & Orchestration:** `LangChain`, `LlamaIndex`
* **Vector Databases & Retrieval (RAG):** `ChromaDB`, `Pinecone`, `FAISS`, `Milvus`
* **Prompt Engineering:** Advanced techniques including Few-Shot prompting, Chain-of-Thought (CoT), and ReAct frameworks.

### 3. Agentic AI & Multi-Agent Systems
* **Autonomous Agent Frameworks:** `CrewAI`, `AutoGen`, `LangGraph`
* **Core Concepts:** Goal-driven autonomous agents, tool usage/function calling, memory management, and multi-agent collaborative workflows.

### 4. MLOps & Deployment (Backend APIs)
* **API Development:** `FastAPI` (for high-performance, asynchronous ML serving), `Flask` (for lightweight, robust web routing)
* **Containerization & Cloud:** `Docker`
* **Environment Management:** `Python-dotenv`, `Conda`, `Pipenv`
